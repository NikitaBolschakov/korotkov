# Павел Коротков — лендинг дегустаций

Статический адаптивный лендинг на HTML, CSS и JavaScript. Сборка и npm-зависимости не нужны.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Для локального сервера можно выполнить из папки проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Структура

- `index.html` — разметка страницы.
- `css/style.css` — точка подключения стилей через `@import`.
- `css/vars.css` — CSS-переменные.
- `css/normalize.css` — normalize.
- `css/globals.css` — глобальные стили, контейнеры и кнопки.
- `css/blocks/` — стили отдельных БЭМ-блоков; media-запросы находятся в соответствующих файлах после основных селекторов.
- `js/main.js` — мобильная навигация, FAQ-аккордеон и демонстрационная обработка формы.
- `assets/` — изображения, извлечённые из предоставленного референса для локального использования.

## Перед публикацией

Форма сейчас работает как демонстрация на стороне браузера: после успешной проверки полей показывает сообщение и очищает форму. Для приёма реальных заявок подключите API/CRM в обработчике `submit` в `js/main.js`. Замените демонстрационные контакты и ссылки соцсетей на актуальные.

Шрифты Oswald и Montserrat загружаются с Google Fonts; при отсутствии соединения с интернетом браузер использует запасные системные sans-serif-шрифты.
